# Контракт ядра и API

## Ядро: `assistant.answer(question, history) -> dict`

Одна функция для `solution.py` (платформа) и веб-API. Сигнатуру и поля меняем только по согласованию с CTO.

**Вход**
- `question: str` - последняя реплика пользователя;
- `history: list[{"role": "user" | "assistant", "content": str}]` - предыдущие реплики (может быть пустым).

На платформе история приходит внутри текста вопроса; `assistant.split_dialog()` разбирает её в этот формат.

**Выход**
```json
{
  "answer": "Арендная плата - 450 000 рублей в месяц, включая НДС (договор аренды № А-08/2024, п. 3.1).",
  "status": "answered",
  "sources": [
    {"doc_id": "lease-a08-2024", "doc_title": "Договор аренды № А-08/2024",
     "point": "п. 3.1", "text": "3.1. Арендная плата составляет ...", "score": 0.91}
  ]
}
```

| status | Когда |
|---|---|
| `answered` | Ответ полностью подтверждён базой |
| `partial` | Найдено не всё: отвечаем по найденному и пишем, чего не хватает |
| `refused_no_data` | В базе нет ничего релевантного |
| `refused_offtopic` | Вопрос не юридический |
| `refused_illegal` | Запрос на противоправные действия |

## Веб-API (FastAPI, порт 8000)

| Метод | Путь | Описание |
|---|---|---|
| GET | `/health` | Проверка работы |
| POST | `/ask` | `{"question": str, "history": [...]}` -> выход ядра |
| GET | `/documents` | Список документов |
| GET | `/documents/{doc_id}` | Текст документа (для просмотра и подсветки фрагмента) |
| GET | `/documents/{doc_id}` | Текст документа, список его структурных чанков (`chunks`) и подсветка (`?point=п. 3.1` -> `highlight`) |
| GET | `/chunks/{chunk_id}` | Конкретный фрагмент документа с разделом (`section`), пунктом (`point`) и координатами (`start_char`, `end_char`) |
